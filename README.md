About

A smart vocabulary learning tool that delivers a **daily quiz of 5 new words** in the user's chosen language.

Features

* 🌐 Choose your preferred language
* 📝 Daily 5-word quiz
* 📊 Score & progress tracking
* 🔥 Learning streaks
* 🔄 Smart revision of missed words
* 🎯 Personalized practice

How It Works ?

**Learn → Quiz → Track → Revise → Improve**

The system identifies missed words and brings them back more frequently to improve **retention and vocabulary growth**.
